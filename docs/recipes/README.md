# 실전 조합

컴포넌트 하나하나가 아니라, 그것들을 엮어 실제 화면을 짓는 방법을 담습니다. 스물여섯 개를 다 외워도 "그래서 폼은 어떻게 앉히지, 표 위 필터 바는 뭘로 짓지"가 남습니다. 이 묶음은 그 빈자리를 메웁니다 — 복잡한 웹앱에서 반복되는 몇 가지 조합을, 그대로 가져다 쓸 수 있는 코드로 보여줍니다.

세 편입니다.

- [폼 한 벌](/docs/recipes/form) — Label·Field·Select·Checkbox·Button을 하나의 입력 화면으로. 정렬과 검증 표시가 어디서 오는지.
- [필터 + 데이터 표](/docs/recipes/data-view) — Tabs·Select·Checkbox로 짠 필터 바 아래 Table과 status Badge. 데모(이슈 트래커)의 뼈대입니다.
- [모달로 만드는 생성 흐름](/docs/recipes/dialog) — Modal 안에 폼을 담아 "새로 만들기"를 처리하는 패턴.

여기 코드는 전부 스물여섯 개 안에서만 조립됩니다. 새 컴포넌트를 끌어오지 않고도 이만큼 서는 걸 보이는 게 이 묶음의 목적이기도 합니다 — 늘리기 전에 조합으로 풀 수 있는지 먼저 보는, [원칙 다섯](/docs/get-started/principles)의 태도입니다. 살아 있는 화면으로 보려면 [데모](/demo)를, 개별 prop을 만져보려면 [플레이그라운드](/playground)를 함께 여세요.
