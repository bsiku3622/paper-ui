# Overview

A Component is a finished part that joins a few Atoms and Primitives to do one job. If an Atom is one control and a Primitive is one device, a Component is what only stands when several pieces move together, such as a grid or a popup. It makes no new colour, line or size, and uses the roles of Foundations and the axes of the Atoms as they are.
