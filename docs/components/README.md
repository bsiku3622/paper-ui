# Overview

Component는 Atom 몇 개와 Primitive를 엮어 한 가지 일을 끝내는 완성 부품입니다. Atom이 컨트롤 하나이고 Primitive가 장치 하나라면, Component는 격자나 팝업처럼 여러 조각이 함께 움직여야 서는 것입니다. 색 · 선 · 크기는 새로 만들지 않고 Foundations의 역할과 Atom의 축을 그대로 씁니다.

| Component | 하는 일 | 문서 |
| --- | --- | --- |
| Calendar | 한 달 격자에서 날짜 하나를 고름 | [Calendar · DatePicker](date-picker.md) |
| DatePicker | 입력 틀 모습의 단추가 Calendar를 팝업으로 엶 | [Calendar · DatePicker](date-picker.md) |
