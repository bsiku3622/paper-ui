# A11y

A11y Primitive는 보조 기술과 키보드 사용자를 위한 1차 바탕입니다. 포커스를 가두고 되돌리는 범위, 화면에서 숨기되 읽히는 콘텐츠, 자식을 다른 자리로 옮기면서도 열린 자리의 모드를 잇는 Portal입니다. 모두 자기 기하(geometry)를 갖지 않습니다. 그룹 하나에 Tab 정지 하나를 두는 탐색은 [Focus](focus.md)가, 입력과 그 설명 · 오류의 연결은 [Field](field.md)가 맡습니다.

| 컴포넌트 | Hook | 책임 | 기본값 |
| --- | --- | --- | --- |
| FocusScope | useFocusRing · useFocusWithin | contain / restoreFocus / autoFocus | 각 기능 opt-in. 범위의 초기 포커스 · 유지 · 복귀 |
| VisuallyHidden | — | as, focusable, children, ref | span. 접근성 트리에 남기며 focusable은 skip link용 |
| Portal | — | container, children | document.body. display: contents 루트 하나가 열린 자리의 테마를 겁니다 |

## Focus와 숨긴 콘텐츠

FocusScope(`FocusScopeProps`: contain · restoreFocus · autoFocus · children)는 세 옵션을 독립적으로 선택합니다. Contain은 기본으로 켜지지 않습니다. Scope가 해제되면 restoreFocus가 원래 요소로 포커스를 돌려줍니다. 유저가 명시적으로 연 화면에서 초기 포커스를 선택하는 예시는 다음과 같습니다.

```tsx
<FocusScope contain restoreFocus autoFocus>
  <Field aria-label="첫 입력" />
  <Button onClick={close}>닫기</Button>
</FocusScope>
```

useFocusRing은 focusProps·isFocused·isFocusVisible을 반환하고, focusProps에는 data-focused · data-focus-visible이 들어 있습니다. within 옵션으로 자식의 포커스도 포함하고, textInput 옵션은 텍스트 입력이라 어떤 focus에서도 링을 보이게 합니다. useFocusWithin은 focusWithinProps·isFocusWithin과 focus 진입·이탈·변경 callback(`FocusWithinOptions`)을 제공합니다.

VisuallyHidden은 콘텐츠를 시각적으로 숨기고 접근성 트리에 유지합니다. as 기본값은 span이며 ref를 그 요소로 전달하고, focusable을 켜면 내부 포커스가 들어올 때 보이게 합니다. Icon button의 이름과 skip link에 사용하는 예시입니다.

```tsx
<Pressable>
  <Icon><path d="M12 4v16M4 12h16" /></Icon>
  <VisuallyHidden>새 항목 추가</VisuallyHidden>
</Pressable>

<VisuallyHidden focusable>
  <a href="#main-content">본문으로 건너뛰기</a>
</VisuallyHidden>
```

동작 예제는 Playground의 Primitives 목록에서 확인합니다. 입력·포커스 계약은 단위 테스트와 실제 브라우저의 pointer·keyboard 경로로 검증합니다.

## Portal

[contract:primitives.portal.root]: #
Portal은 자식을 container(기본은 `document.body`)로 옮기고, 그 자리에 root 하나를 둡니다. root는 `display: contents`라 자기 상자가 없고, 열린 자리의 테마(`usePortalScope`)를 속성으로 다시 걸어 옮겨진 내용이 열린 자리의 모드로 그려지게 합니다. 패키지의 모든 portal이 이 길을 지나므로 [Floating](float.md)의 panel과 backdrop은 테마 속성을 직접 쓰지 않습니다. 임의의 지역 CSS 상속이 필요하면 `container`로 그 Element를 지정합니다.

```tsx
<Portal container={dialogHost}>
  <Surface fill="raised" border radius="md" padding="md">옮겨진 내용</Surface>
</Portal>
```
